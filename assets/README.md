# Какие файлы положить в папку assets

Экспортируйте из Figma и назовите файлы ровно так. Пока файла нет, на его месте показывается заглушка.

| Файл | Что это | Как экспортировать |
|---|---|---|
| avatar.webp | фото в бейдже | ✅ готово |
| avatar-2…5.webp | фото, которые сменяются при наведении на бейдж | ✅ готово |
| lanyard.png | шнурок с карабином | ✅ готово |
| cv.pdf | резюме для кнопки Download CV | ✅ готово |
| tools/figma.svg | иконка Figma | ✅ готово |
| tools/photoshop.svg | иконка Photoshop | ✅ готово |
| tools/claude.svg | иконка Claude | ✅ готово |
| tools/chatgpt.svg | иконка ChatGPT | ✅ готово |
| tools/obsidian.svg | иконка Obsidian | ✅ готово |
| cases/neura.webp | обложка кейса Neura | ✅ готово |
| cases/nomey.webp | обложка Nomey | ✅ готово |
| cases/gaitor.webp | обложка Gaitor | ✅ готово |
| cases/design-system.webp | плитка Design System | ✅ готово |
| cases/flonk.webp | заглушка Flonk (KYC & KYB) | ✅ готово |

Обложки кейсов экспортируйте без кнопки со стрелкой: она сделана в коде.
